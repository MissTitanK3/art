## 🎯 Why Visual Alerts?

Text alone gets lost. Graphic-style alerts:
- Draw attention in group chats or Telegram
- Train people to recognize urgent calls to action
- Signal that something matters **right now**
- Help people screenshot/share without confusion

But: sloppy graphics or wrong language can **expose risks or confuse your audience**.

## 📸 When to Use a Visual Alert

| Scenario                          | Use Visual Alert? |
|-----------------------------------|-------------------|
| 🚨 Rapid ICE/police report        | ✅ Yes — use action visual |
| 📅 Scheduled protest/event        | ✅ Yes — use “upcoming” format |
| 📍 Location-specific support need | ✅ Yes — but watch GPS leaks |
| ❗Confidential coordination        | ❌ No — use Signal text only |
| 🔁 Reposting from another org     | ✅ Yes — if verified & credited |

## 🧰 The Visual Alert Toolkit

**Required Elements:**
- ⚠️ Strong visual icon (🚨, 🔥, ⛑️, 📍, etc.)
- 🕒 Timestamp or urgency word (“Happening now”, “This Weekend”)
- 🌐 Action type (“Report ICE”, “Mutual Aid Needed”, “Training”)
- 🎯 Clear call to action
- ✅ Verified source tag (like "ART Alert")

**Avoid:**
- Exact addresses (use cross-streets or neighborhoods)  
- Faces, names, or identifying info  
- Mention of planned illegal activity  
- Exif/photo metadata (remove before sharing!)  

---

## 🖌️ Visual Style Standards (So Far)

| Element       | Why It Matters                        |
|---------------|----------------------------------------|
| Consistent header | Helps people recognize it’s official |
| Emoji or icon | Signals tone and urgency              |
| Monochrome colors | Better for printing + contrast      |
| Bold + clear text | Easy to screenshot + share         |

<Callout type="hint">
Use one consistent **font + color style** across all alerts to make them recognizable at a glance.
</Callout>

## 🧱 Templates You Can Reuse

Start with these base layouts:

### 🚨 “Action Alert” Format
- Red border  
- Large emoji top left (🚨 or 🛑)  
- Bold title: “Urgent ICE Sighting”  
- Key info: area, report source, suggested response  
- Footer: “Report updates to Watch / Dispatch”

### 🧊 “Cold Zone Update”
- Blue tones  
- “NO PRESENCE REPORTED” label  
- Encourages people to stay vigilant and rest

### 🧰 “Support Needed” / Logistics Call
- Green tones  
- Icons: 🛠️, 🍱, 🚗  
- Field: Who/What/Where/When/How to help  
- Includes contact method (never full name)

---

## 🖼️ Hosting Templates (Canva, Figma, etc.)

Choose a **template platform** that:

- Doesn’t require login to view or copy  
- Can be locked down to avoid overwrites  
- Can be edited quickly from mobile or browser  
- Works offline or allows downloads as PNG

📍 **Recommended:**  
- [Canva (public template mode)](https://www.canva.com/)  
- Figma (for dispatch/design teams only)  
- Google Slides (if offline export is needed)

## 🚨 Example Alert Breakdown

> _Visual contains:_  
> - “📍 ICE Presence reported”  
> - “South Tacoma Way, near 88th”  
> - “Stay alert. Log updates via ART Watch.”  
> - “🛠️ Mutual Aid Team en route”

✅ Good:
- No names, faces, or addresses  
- Clear action and context  
- Familiar emoji style

⚠️ Avoid this:
- “We’re heading there with gear — meet us at 11am”
- “Police scanner confirms detainments” (unless verified + public)

## 🧠 Design + OPSEC Rules

| Rule | What It Prevents |
|------|------------------|
| Never use real faces | Prevents ID via photo/video matching |
| Avoid detailed addresses | Prevents geofence tracking |
| Always strip image metadata | Prevents GPS/location leakage |
| Don’t pre-announce presence | Prevents ambush or entrapment |

---

## ✅ Process for Making & Sharing

1. Open base template  
2. Insert only verified info (area, timing, purpose)  
3. Export as PNG or image  
4. Drop into Signal/Telegram with 1–2 line caption  
5. (Optional) Add hashtags if going public  
6. (Optional) Share to socials with **caption warnings** like:
   > ⚠️ Do not show up unless you're trained and aware of risks. This is for internal alerting.

---

## 📋 Sharing Protocols

| Platform      | Cautions                     | Notes |
|---------------|------------------------------|-------|
| Signal        | Don’t overuse visuals         | Only for real urgency |
| Telegram      | Public channels = high risk   | Assume surveillance |
| Instagram     | Use graphic, not caption      | Don't tag people |
| Bluesky / TikTok | Avoid real-time locations | Post with 1–2 hour delay |

<Callout type="warn">
Do not post alerts from unverified sources or emotional hearsay. False alerts destroy trust and endanger people.
</Callout>

## Practice Scenario

🧠 _A team member sends a Signal message: “ICE at Walmart. Near 74th & Hosmer.”_

What visual alert steps do you take?

✅ Checklist:
- [ ] Confirm: Who saw it? Can it be verified?
- [ ] Choose correct template (“Urgent ICE Sighting”)
- [ ] Use nearest intersection, not address
- [ ] Do **not** say who's responding
- [ ] Share with caption:  
  > “🚨 ICE REPORTED NEAR 74th & Hosmer (Tacoma)  
  > Report updates via ART Watch.  
  > Avoid scene unless trained.”

## 🧠 Final Notes

- Use visuals **to prompt action**, not just awareness  
- **Train people to expect and understand them**  
- Maintain a shared style across all pods and dispatchers  
- Archive visuals with metadata removed (for debrief + safety)
