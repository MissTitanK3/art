# 📢 Designing Secure, Visual Alerts
<TrackBadge variant="dispatch" />
<TrackBadge variant="media-awareness" />
<TrackBadge variant="security" />

<Callout type="info">
Signal alerts can get buried. Learn to design safe, recognizable visuals that cut through noise and drive coordinated action — without exposing sensitive info.
</Callout>

---

## Why Visual Alerts Matter

Text alone disappears in busy chats. A clear visual:
- Draws attention quickly
- Builds trust and recognition
- Helps teams screenshot/share accurately
- Encourages disciplined, verified messaging

⚠️ Bad visuals can leak info or cause confusion. Always prioritize security over aesthetics.

## When to Use a Visual Alert

| Scenario | Use Visual Alert? |
|-----------|-------------------|
| 🚨 Rapid ICE/police report | ✅ Yes — use urgent format |
| 📅 Upcoming protest or event | ✅ Yes — event-style visual |
| 📍 Support needed in specific zone | ✅ Yes — avoid GPS leaks |
| ❗Confidential coordination | ❌ No — text only |
| 🔁 Reposting another org | ✅ Yes — only if verified |

---

## Visual Alert Toolkit

**Include:**
- ⚠️ Urgency icon or emoji  
- 🕒 Clear timestamp (“Now,” “Tonight,” “Ongoing”)  
- 🌐 Action type (“ICE Report,” “Mutual Aid,” “Training”)  
- 🎯 Call to action  
- ✅ Verified source tag (e.g., “ART Alert”)  

**Never include:**
- Exact addresses or faces  
- Real names or identifiable vehicles  
- Planned movements or times  
- Metadata (always strip before sharing)

---

## Visual Style Standards

| Element | Why |
|----------|-----|
| Consistent header | Builds instant trust |
| Monochrome palette | Improves contrast and print visibility |
| Bold text | Readable in screenshots |
| Icon or emoji | Instantly signals urgency |

<Callout type="hint">
Stick to one font and color scheme across all visuals so pods recognize your alerts immediately.
</Callout>

---

## Template Formats

### 🚨 Action Alert
- Red accent
- Large emoji or icon
- Headline: “Urgent ICE Sighting”
- Fields: Area, verified source, response note
- Footer: “Report updates via Watch / Dispatch”

### 🧊 Cold Zone Update
- Blue palette
- “No Presence Reported” message
- Reinforces calm and vigilance

### 🧰 Support Needed / Logistics Call
- Green palette
- Icons: 🛠️, 🚗, 🍱
- Fields: Who / What / Where / When / Contact method (no names)

## Hosting Templates

Use a platform that:
- Allows viewing/copying without login  
- Locks templates from accidental overwrite  
- Works offline or supports PNG export  

**Recommended:**  
- [Canva (public templates)](https://www.canva.com/)  
- Figma (internal teams only)  
- Google Slides (offline safe mode)

## Example Breakdown

✅ Safe:
> “📍 ICE Presence — South Tacoma Way near 88th.  
> Log updates via Community Watch.”

⚠️ Unsafe:
> “We’re deploying at 11am — bring gear.”  
> “Police scanner confirms detainments.”

---

## Design + OPSEC Rules

| Rule | Prevents |
|------|-----------|
| No faces | Avoids ID exposure |
| No specific addresses | Blocks GPS targeting |
| Strip metadata | Removes location leaks |
| Don’t pre-announce | Avoids interception |

---

## Process for Making and Sharing

1. Open base template  
2. Add verified info only (no speculation)  
3. Export as image  
4. Share with minimal caption  
5. (Optional) Use hashtags only for verified public alerts  
6. Review metadata and file name before posting  

**Caption example:**
> 🚨 ICE reported near 74th & Hosmer (Tacoma)  
> Report updates via Community Watch.  
> Avoid the area unless trained.

---

## Platform Protocols

| Platform | Caution | Note |
|-----------|----------|------|
| Signal | Avoid overuse | For urgent alerts only |
| Telegram | Assume monitoring | Public channels unsafe |
| Instagram | Post graphic only | No tags or faces |
| TikTok / Bluesky | Delay posts 1–2 hours | Prevent live tracking |

<Callout type="warning">
Do not post unverified or emotional alerts.  
False info destroys trust and can endanger responders.
</Callout>

## Practice Drill

A volunteer messages:  
> “ICE at Walmart near 74th & Hosmer.”

Steps:
- Verify source  
- Choose “Urgent ICE” template  
- Use nearest intersection, not address  
- Avoid identifying responders  
- Caption with verified call to action
