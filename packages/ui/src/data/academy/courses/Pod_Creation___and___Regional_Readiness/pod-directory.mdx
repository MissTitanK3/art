## What This Directory Is

The **General Pod Directory** lists open, moderated **Signal pods** that act as **entry points** to the Always Ready Tools network.  
They are not command centers — they’re gathering points to help new members **connect, learn, and build trust**.

If you’re new, start here.  
If you’re forming a pod, connect and announce your intent.  
If you’re already part of one, help others find a path in.

<Callout type="important">
Most listed pods are **entry-level** spaces. Trust is always **local and relational**, not global or automatic.  
Many pods use “outer” and “inner” layers — one open for newcomers, one reserved for verified members.
</Callout>

<Callout type="hint">
Keep your pod secure:
- Use encrypted messaging only.  
- Avoid storing logs or PII.  
- Delete notes after review.  
- Always get consent before sharing contact info.
</Callout>

## Pod Types (Quick Reference)

| Pod Type | Access | Purpose |
|-----------|---------|----------|
| **General Pod** | Open or moderated | Entry-level space for connection |
| **Regional Pod** | Lightly vetted | Area coordination & training |
| **Neighborhood Pod** | Vetted | Trusted field operations |
| **Ops Pod** | Invite-only | Specialized dispatch, medics, legal, etc. |

### [Name] General Pod
- **Platform:** Signal  
- **Link:** Request via @[name]-trusted-mod  
- **Contact:** @[name]-trusted-mod  
- **Coverage:** Towns, counties, or regional notes
</Callout>

<Callout type="info">
🧠 **Trust & Access Note**  
Ask how a pod handles onboarding and layered access before joining.  
Some pods require in-person verification, others use cross-pod vouching.
</Callout>
