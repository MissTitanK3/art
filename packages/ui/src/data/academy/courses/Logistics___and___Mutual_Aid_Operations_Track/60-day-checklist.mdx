# 🗓️ 60-Day Checklist: Weekly Community Readiness Plan
<TrackBadge variant="logistics" />

<Callout type="info">
Use this guide to build readiness one week at a time.  
Each week adds small, doable steps to grow safety, trust, and self-reliance without overwhelm.
</Callout>

<Callout type="hint">
Pairs with [60-Day Preparedness](/courses/60-day-preparedness).  
Use both together for strategy + action.
</Callout>

---

## Overview

This plan helps pods strengthen together across eight weeks.  
Each section includes concrete goals, average time, and collaborative focus.  
Expect about **30–60 minutes of effort per week**.

> You don’t need a bunker. You need trusted people, clear plans, and flexible systems.

---

## Weekly Objectives

### 🧩 Week 1 – Foundations
- [ ] Read “Rule of 3s” → [Jump to section](/courses/60-day-preparedness#the-rule-of-3s-visual-priority-pyramid)  
- [ ] Form a 2–5 person pod → [Create a Pod](/courses/create-a-pod)  
- [ ] Save local emergency contacts offline  
- [ ] Store 3 days of water per person (1 gal/day)  
- [ ] Review power-outage and medication-cooling plan  

---

### 📡 Week 2 – Communication
- [ ] Join or create a **Signal** group → [Signal Tips](/courses/signal-tips)  
- [ ] Create a **call tree / check-in** system  
- [ ] Share map of trusted meeting spots (printed + visual)  
- [ ] Send a **test alert** and confirm delivery  
- [ ] Print offline contact sheet  

---

### 🪪 Week 3 – Documentation & Identification
- [ ] Gather **Red Cards / KYR cards** → [KYR Basics](/courses/kyr-basics)  
- [ ] Discuss **consent + documentation ethics**  
- [ ] Test **face-blurring tools** (ObscuraCam / Pixelate.online)  
- [ ] Practice **secure note-taking** → [Documentation Safety](/courses/documentation-safety)  
- [ ] Set **retention + deletion** timelines  

---

### 🥫 Week 4 – Food, Meds, and Tradeables
- [ ] Store 7 days of food per person (bulk basics save costs)  
- [ ] Track **essential meds + refills**  
- [ ] Build a **barter / trade list** (batteries, hygiene, OTC supplies)  
- [ ] Label **dietary + allergy** needs  
- [ ] Review **safe food-sharing** practices  

---

### 🏠 Week 5 – Movement & Shelter
- [ ] Identify 2–3 fallback locations  
- [ ] Map evacuation routes (foot + vehicle)  
- [ ] Plan backup transport (bike, rideshare, runner)  
- [ ] Pack a go-bag (meds, docs, basics)  
- [ ] Record accessible locations for disabled members  

---

### ⚙️ Week 6 – Tools, Power, and Repairs
- [ ] Test battery lights + radios  
- [ ] Charge solar banks / spares  
- [ ] Inventory shared tools (multi-tools, chargers, radios)  
- [ ] Label by skillset (tech, repair, care)  
- [ ] Start or join a **tool library**  

---

### 🔁 Week 7 – Simulations & Triggers
- [ ] Pick one trigger event (e.g. power + comms loss) → simulate  
- [ ] Run a meeting without digital tools (signs / notes)  
- [ ] Practice analog distress signals (whistles, chalk, runners)  
- [ ] Check expiration dates on supplies  
- [ ] Revisit the [Readiness Grid](/courses/60-day-preparedness#readiness-grid)  

---

### 🌱 Week 8 – Rebuilding & Reflection
- [ ] Add two new contacts or skill-share allies  
- [ ] Log learnings + remaining gaps  
- [ ] Identify local ally orgs and translate materials  
- [ ] Review consent practices and Red Lines  
- [ ] Optional: Start a garden or seed swap  

---

## Reflection

How has your pod’s trust changed since Week 1?  
Which habit feels most sustainable long-term?  
Where can you include more language access or disability support?
