## Overview

Phones, Wi-Fi, and the internet can fail or be blocked during crises.  
Mesh networks allow volunteers to stay connected **without relying on external infrastructure**.

**Meshtastic** uses low-power LoRa radios to send encrypted messages directly between devices — forming a resilient communication web.

Ideal for:
- Protests or marches  
- Mutual aid and disaster zones  
- Rural pods with no service  
- Situations where privacy or uptime matter  

---

## Learn & Do

### 1. What a Mesh Network Is

A mesh network is a **self-healing web of radios**.  
Each radio, or **node**, passes messages until they reach their destination.

| Concept | Meaning |
|----------|----------|
| **Node** | A single radio device on the network |
| **Hop** | When one node relays a message to another |
| **Channel** | A shared encrypted room of communication |
| **Mesh** | The connected network of nodes sharing traffic |

<Mermaid chart={`graph TD
A[Message Sent] --> B[Node 1 Relays]
B --> C[Node 2 Relays]
C --> D[Node 3 Receives]
E[Offline Node] -.->|No effect| B
`} />

There’s **no central tower** — if one node goes down, others still connect.

---

### 2. How Meshtastic Works

Meshtastic is open-source software for small LoRa radios.  
Each node:
- Encrypts and relays short text or data packets  
- Connects to your phone via Bluetooth for message control  
- Can run for hours or days depending on battery size  

Approximate range:
- **Urban:** 1–3 km  
- **Rural / line-of-sight:** 5–15 km (or more with elevated relays)

### 4. Quick Start Steps

1. Borrow or set up a Meshtastic node.  
2. Install the **Meshtastic App** (Android/iOS).  
3. Pair via Bluetooth.  
4. Join a **test channel**, not an operational one.  
5. Send and receive your first message.  
6. Test range and battery runtime.  
7. Power down when idle to save energy and reduce signal footprint.

---

### 5. Staying Secure

Even with encryption, LoRa signals are **detectable**.  
Follow these principles:

- Change default channel keys immediately.  
- Never share personal or operational details over mesh.  
- Label nodes with **codenames**, not real names.  
- Transmit only when needed.  
- Power off nodes when not in use or after ops.  

<Callout type="warning">
Encrypted ≠ invisible.  
Signal scanners can still detect transmission bursts.  
Short, infrequent messages reduce traceability.
</Callout>

<Callout type="hint">
Documentation hygiene:  
Avoid storing device logs or chat exports in shared apps.  
Use encrypted, access-controlled notes and delete temporary files.  
ART apps do not store mesh archives by default.
</Callout>

---

### 6. Improving Range

- Keep antennas vertical.  
- Gain elevation (hill, balcony, or rooftop).  
- Avoid dense concrete or metal structures.  
- Position relays strategically between groups.  
- Consider external antennas for large areas.

---

### 7. Drill for Certification

To complete this module:

1. Pair with a partner’s node.  
2. Send and receive **three test messages**.  
3. Demonstrate at least **one hour of runtime** on battery.  
4. Show you can **disable broadcasting** when not needed.  

<Callout type="important">
Consent & legal:  
Always ask before sharing device IDs, logs, or location data.
